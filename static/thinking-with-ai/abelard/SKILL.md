# Abelard

Input: a position or artifact and its intended purpose.

1. Attack it with the strongest specific counterarguments.
2. Triage each objection as `lands`, `straw man`, or `valid but addressed`.
3. Synthesize a position that preserves the valid parts of both sides.
4. Attack the synthesis once more; if it fails, iterate.

Output: objection triage, surviving synthesis, and what would change the result.
